# 🏷️ For-sale - Professional Classifieds Marketplace

**For-sale** is a comprehensive e-commerce platform designed for buying and selling products across diverse categories, including Electronics, Vehicles, and Real Estate. This project highlights a robust implementation of **Firebase Firestore** for real-time synchronization and **Firebase Storage** for efficient media management.

## 🚀 Key Features

- **Multi-Category Listings:** Support for various domains like electronics, cars, and jobs.
- **Real-time Listings:** Instant updates across the platform powered by **Cloud Firestore**.
- **Media Hosting:** Seamless image uploads and hosting via **Firebase Cloud Storage**.
- **Modern UI Architecture:** Implemented using **MVVM** and **Data Binding** for a decoupled and testable codebase.
- **Search & Discovery:** Efficient filtering and sorting to help users find exactly what they need.

---

## 🛠 Tech Stack & Tools

- **Language:** **Java** - Demonstrating long-standing expertise in Android core development.
- **Architecture:** **MVVM** (Model-View-ViewModel) for a scalable and maintainable structure.
- **Dependency Injection:** **Dagger Hilt** - Managing dependencies with industry-standard best practices.
- **Backend:** **Firebase Cloud Firestore** (NoSQL Database).
- **Storage:** **Firebase Storage** for high-performance image handling.
- **UI Toolkit:** **Android Jetpack**, **Data Binding**, and **Material Design** components.

---

## 🏗 Architectural Highlights

As a **Senior Developer**, I focused on several complex implementation details in this project:
- **Scalable Data Schema:** Designed a Firestore structure that allows for fast queries and future expansion.
- **Clean Dependency Graph:** Leveraged **Dagger Hilt** to ensure the app is modular and easy to refactor.
- **Reactive UI:** Used Data Binding to sync the UI with the data source automatically, reducing boilerplate code.
